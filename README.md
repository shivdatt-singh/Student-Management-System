# Student Management System

A web-based Student Management System developed using Python and Django.

## Features

- View the list of students
- Add a new student
- Update student details
- Delete student records
- Simple and user-friendly interface

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite

## Project Purpose

This project was developed to practice Django web development and learn CRUD operations.

CRUD stands for Create, Read, Update, and Delete.

## How to Run the Project

1. Clone this repository.
2. Open the project folder in the terminal.
3. Create and activate a Python virtual environment.
4. Install Django and other required dependencies.
5. Run database migrations.
6. Start the Django development server.
